# 通用表单集成示例（仅测试站）

这是**一个单独的 WordPress 测试插件**，不属于 WEM Inquiry Cart 的核心功能。用于验证现有购物车与网站表单之间的服务端数据交接。

## 最快测试

1. 先安装并启用核心插件 `WEM Inquiry Cart v0.1.4`，设置产品类型，添加至少一件产品。
2. 将 `wem-ic-example-form/` 文件夹复制到 WordPress 的 `wp-content/plugins/`，或上传 `wem-ic-example-form.zip`。
3. 启用插件 **WEM IC Example Form (Testing Only)**。
4. 新建一个仅供测试的 WordPress 页面，输入短代码 `[wem_ic_example_form]`。
5. 在该页面填写 Name、Email、Message，点击 **Run Dry Test**。
6. 看到“模拟测试通过”说明本例的验证和购物车读取逻辑能够运行；**没有发送邮件，也没有清空购物车**。

> 测试页建议设为私密，且在 SiteGround / Cloudflare 等系统中排除页面缓存；不应放在公开导航。

## 可选：测试真实邮件

在**测试站**的 `wp-config.php` 中加入（只为测试而临时开启）：

```php
define( 'WEM_IC_EXAMPLE_ALLOW_EMAIL', true );
```

重新载入表单后，按钮改为 **Send Test Email**。邮件只发往 WordPress **设置 → 常规 → 管理员电子邮箱地址**；示例不会根据用户输入决定收件人，也不使用 EVODEK 的任何地区路由。

- 每个识别访客 60 秒内最多发起一次邮件，10 分钟最多 5 次尝试（简单限流，不代替专业反垃圾机制）。
- `wp_mail()` 返回失败：显示错误，**购物车保留**。
- `wp_mail()` 返回成功：显示提示，**清空当前访客购物车**；但仍须在管理员收件箱检查实际投递是否成功。
- 测试完立即移除该常量，停用并删除示例插件。

## 接入接口与行为

真实站点的表单可以自选字段与邮件策略；本示例只用 Name、Email、Message 三个字段证明集成方式：

```php
$items = wem_ic_get_cart_items(); // product_id, name, quantity, url, image
// 验证表单、构造邮件、发送成功之后：
wem_ic_clear_cart();
```

示例具体包含：服务器端 Nonce、表单验证、蜜罐字段、服务器读取产品清单、固定测试收件人、发送限频、成功后清空、失败保留、提交后重定向避免刷新重复发送。

**重要：** 本例不是生产级表单解决方案；公共生产环境需要针对具体表单完善隐私政策、可交付性监控、更严密的反垃圾、跨节点限频与重试控制。它不会创建数据库订单、保存个人信息或自动生成页面。

## 不做的事情

- 不改动核心购物车插件中的任何 PHP/CSS/JS。
- 不处理真实客户地区分配、SMTP 授权码、站点私有信息。
- 不使用浏览器隐藏字段作为真实商品清单。
- 不会在安装核心插件时自动启用该示例。
